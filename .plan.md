# Interleaved Sub-Question Answering — Implementation Plan

## Goal
Implement interleaved sub-question answering in `questionFlow.ts` (Pipeline 2, LangGraph).
- Decompose upfront (already works), but answer sub-questions **one-by-one sequentially**
- Each sub-question's answer gets all previous Q&A pairs as context
- **No final synthesis step for now** — pipeline outputs the collection of sub-Q&A pairs

## New Graph Flow

### Decomposed (complex question):
```
START → decomposition_node → gather_info → answering_node → [router]
                                ↑                               |
                                |___ (more sub-Qs to answer) ___|
                                                                |
                                                     (all sub-Qs done) → END
```

### Non-decomposed (simple question):
```
START → decomposition_node → gather_info → answering_node → [router] → END
```

## Node Behavior

| Node | What it does |
|---|---|
| **decomposition_node** | *(no changes)* Decomposes or not. Sets `questionStack` & `questionIndex`. |
| **gather_information_node** | *(minor tweak)* Retrieves chunks/external info for the current sub-question or original question. When decomposed & `questionIndex == -1` (all done), skip retrieval. |
| **answering_node** | **NEW logic.** If sub-question (index ≥ 0): answers it using retrieved context + all previous Q&A pairs, stores answer in `questionStack`, decrements `questionIndex`. If simple question (index == -1, not decomposed): answers original question using `answerGenerationPrompt`. |
| **router** *(conditional edge)* | If `questionIndex ≥ 0` → loop back to `gather_information_node`. Otherwise → `END`. |

## Sub-Question Processing Order
`decomposition_node` stores sub-questions in reverse order with `unshift`:
- `questionStack` = [dependent, ..., foundational]
- `questionIndex` starts at highest index (foundational)
- Processes from high→low index: foundational → ... → dependent
- Previous Q&A = items with index > current `questionIndex`, reversed to foundational-first order
